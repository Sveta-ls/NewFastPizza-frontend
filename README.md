# NewFastPizza — главная страница

Готовая клиентская главная страница на React + TypeScript + Vite. Визуальная основа — предоставленные референсы NewFastPizza.

## Что реализовано

- Адаптивная главная страница для desktop, tablet и mobile.
- Шапка с навигацией, логотипом, аккаунтом и корзиной.
- Первый экран с крупной фотографией пиццы и подписями ингредиентов.
- Рабочая карусель из четырёх пицц: меняются фото и подписи ингредиентов.
- Блок популярных пицц.
- Добавление пицц в демонстрационную корзину, изменение количества и пересчёт суммы.
- Выдвижная корзина и уведомления.
- Блок доставки, преимуществ и футер.

## Требования

- Node.js 18.18+ (рекомендуется Node.js 20 LTS)
- npm

## Как запустить

1. Распакуйте архив `NewFastPizza-homepage.zip`.
2. Откройте папку `NewFastPizza-homepage` в VS Code.
3. Откройте терминал в этой папке.
4. Установите зависимости:

   ```bash
   npm install
   ```

5. Запустите dev-сервер:

   ```bash
   npm run dev
   ```

6. Перейдите по адресу, который появится в терминале. Обычно это:

   `http://localhost:5173`

Чтобы остановить сервер, нажмите `Ctrl + C` в терминале.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Важно

Это первый согласовательный этап — только главная страница. Корзина здесь демонстрационная и хранится в состоянии React: она не отправляет заказ на сервер и сбрасывается после перезагрузки. Авторизация, реальные маршруты, API, карта и полноценное оформление заказа будут подключаться на следующих этапах.

Фотографии товаров в папке `src/assets` извлечены из предоставленных дизайн-референсов. Шрифт Manrope загружается из Google Fonts; для его загрузки требуется интернет-соединение. Если сеть недоступна, используется системный sans-serif.
